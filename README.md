## 🎨 Philosophy

**MD Forge** is designed for those who appreciate clarity and focus. It strips away the unnecessary, leaving a pure, solid, and elegant environment for writing and converting Markdown. Whether you're drafting technical docs, rendering Mermaid charts, or exporting to PDF, it feels like a native macOS application right in your browser.

## ✨ Features

- **Real-Time Split View:** Instantly see your rendered Markdown as you type.
- **Drag & Drop Magic:** Drop one or multiple `.md` files directly into the beautifully designed dropzone.
- **Multi-Format Export:** Seamlessly convert your work to **HTML**, **PDF**, or **DOCX** with a single click.
- **Advanced PDF Settings:** Customize your exports with Page Size (A4, Letter, Legal, A3), Orientation, Margins, and 5 distinct Border Styles.
- **Mermaid Support:** Write diagrams (Pie, Gantt, Sequence, Flowcharts) natively inside your Markdown with vibrant colors.
- **Dark & Light Modes:** Flawless theme switching with pure, solid Apple-style background colors (`#f5f5f7` & `#000000`).
- **Bulk Export:** Export dozens of Markdown files into a single ZIP archive instantly.

## 🚀 Installation

MD Forge is a lightning-fast Vite application. Getting started is simple:

```bash
# 1. Clone the repository
git clone https://github.com/ybehruzbek/md-forge.git

# 2. Navigate to the project directory
cd md-forge

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Visit `http://localhost:4200` to experience MD Forge.

## 📄 Export Options

MD Forge isn't just about viewing; it's about delivering professional documents.

* **HTML:** Standalone, themed HTML files with premium print bars and `@page` CSS rules.
* **PDF:** High-quality PDF generation using `html2pdf.js` with full control over margins and page size.
* **DOCX:** Native Word document generation via `html-docx-js` for seamless corporate sharing.

## 🖌 Themes

Your exports, your style. Choose from carefully crafted export themes:
- **Clean White:** The standard, pure Apple aesthetic.
- **Dark Elegant:** Deep contrast for modern documentation.
- **Academic:** Serif fonts and strict margins for papers and research.
- **Minimal:** No borders, no distractions.
